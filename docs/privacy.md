# Wilthy 隐私条款

本页说明你的数据存放在哪里，以及哪些内容会离开你的设备。使用本软件时的责任划分见[《Wilthy 使用条款》](terms.md)。

最后更新：2026-11-25

## 1. 数据保存在本机

**本软件没有远程数据库，也不把你的数据上传给开发者**。你的对话、资料与各项设置都保存在你的设备上。界面不直接读写数据库与凭据文件，只通过预加载接口请求主进程。

应用数据目录（Electron 的 userData，Windows 上通常是 %APPDATA%\Wilthy）下：

- SQLite 数据库 wilthy.db：会话索引、邮件与课程等同步数据、笔记与文件的索引、通知、各项设置，以及条款接受记录（哪一份、哪一版的条款，以及接受时间与应用版本）。
- 对话的完整记录：pi/sessions 下的 JSONL 文件，由 Agent 内核写入；数据库里只有这些会话的索引。
- 其他文件：对话中发送的图片与文档附件副本（chat-media/）、邮件草稿（mail-drafts/）、远端项目的内容镜像（remote-context/）、打开过的教务部通知 PDF 缓存（jwc-files/），以及旧版数据库的整库备份（wilthy-legacy-backup.db）。文档副本保留供后续追问，启动时清理没有会话引用的图片与文档；未发送的文档附件在你移除时删除。
- 界面状态：Chromium 的 Local Storage（userData/Local Storage）里存着侧栏与各面板的折叠状态和宽度、已看过的更新版本、主题与字号、聊天草稿，以及引导步骤与你的同意标记。
- 你主动导出的备份：在条款接受页选择位置后，主进程把应用数据、工作目录、你自己的 Skill 与 `~/.wilthy` 下的配置文件复制过去（跳过可再生的 Chromium 缓存，数据库取一致快照）。这是一次本地文件复制，不联网；副本里含有凭据文件、明文 API Key 与数据库，请保存到你信任的位置。

同一目录下的加密凭据文件：

| 凭据文件             | 保存的内容                               |
| -------------------- | ---------------------------------------- |
| mail-credentials.bin | 邮箱地址与密码（北师邮箱为客户端授权码） |
| campus-session.bin   | 数字京师·珠海与教务系统的登录会话 Cookie |
| mineru-token.bin     | MinerU API Token                         |

用户主目录下 `~/.wilthy` 中的**明文**配置文件，你和 magpie 等工具可以直接编辑：

| 配置文件    | 保存的内容                                                    |
| ----------- | ------------------------------------------------------------- |
| config.json | 模型服务的地址、API Key 与模型设置；联网搜索服务的 API Key 等 |
| mcp.json    | MCP 服务器的命令、参数、环境变量、地址与请求头                |
| skills/     | 内置 Skill 与你自己安装的 Skill                               |

3.0 及更早版本加密保存的模型服务与 MCP 配置（llm-providers.bin、mcp-servers.bin）在升级后移入上面的文件并删除。

旧版单凭据文件 model-credential.bin 在升级为多提供商配置后自动删除。

工作目录（默认「文档/Wilthy」，可在 设置 › 工作区 更改）中的文件：笔记的 Markdown 正文与其中的图片，以及导入的文件。

读取文档（read_document）的解析结果按文件内容缓存在系统临时目录的 wilthy-documents 下，包括正文 Markdown 与其中的图片，超过 7 天的缓存在下次读取时清理。

邮件、课表、成绩、培养方案与教务通知是学校服务的本地副本，可重新同步获取。邮箱密码不写入数据库：数据库里只有邮箱地址、服务器与端口。

## 2. 凭据如何保护

- **凭据文件用 Electron safeStorage 加密后写入，解密能力由操作系统保管**；系统不支持加密时，应用拒绝读写并给出提示。
- **模型服务、联网搜索与 MCP 的密钥明文保存在 `~/.wilthy`**，文件权限只给当前系统用户读写，分享或同步该目录前请先检查。
- 写入先落临时文件再原子替换；旧文件无法解密时，先备份为「原文件名.unreadable-随机串.bak」再写入新内容，不因重新配置而删除。
- **API Key 与令牌只在主进程内使用**：界面拿到的模型服务配置不含密钥字段；邮箱只返回连接状态与邮箱地址，不含密码；MCP 服务器只返回名称、连接方式与状态，不含命令、地址、环境变量与请求头。
- **密钥不进入模型消息**：请求时由主进程把 API Key 放进 HTTP 请求头，发给模型的内容是对话与资料文本。

## 3. 运行 Agent 时发送到模型服务的内容

**只有在你发送消息、让它继续执行，或在设置中检测密钥时，才会请求模型服务**。请求由主进程直接发出，界面不持有密钥。

- 系统提示词，以及已启用 Skills 的名称与描述索引。
- 你在 设置 › 自定义指令 中填写的全局指令（留空则不发送），它会随每次请求一并发出。
- 当前会话的历史消息；较早历史已生成摘要时，摘要一并发送。
- 本轮引用的资料内容（按需读取的笔记、文件、邮件、课表与成绩等）、附件正文、你输入的文字与图片。
- 工具执行结果会随后续轮次继续发回同一服务。

这些内容发往 设置 › 模型供应商 中启用的地址。**数据保存在本机不等于在本机推理**：应答由你选择的模型服务产生，内容发出后如何保存由该服务决定，本应用不控制。

## 5. 本机记录了什么

**应用运行时不写日志文件**（开发模式的控制台输出只打印在终端，不落盘）。Agent 执行也不单独留档：一次执行的运行状态只存在于内存与界面（导航行上的运行标记），执行过程随对话正文一起写进会话文件（见第 1 节），数据库里的会话索引只记消息计数与最后更新时间。

凭据与密钥不写进会话记录，也不会作为上下文发给模型。

## 6. 本软件没有的功能

- **没有账号服务器**：不需要注册或登录 Wilthy 账号，代码中也没有把数据上传到项目服务器的接口。
- **没有云同步**：换一台设备不会自动带上你的数据，迁移需要自行拷贝工作目录与应用数据目录，或使用条款接受页里的导出。
- **没有使用统计与崩溃上报**：依赖中没有统计分析或崩溃上报的第三方服务，主进程的对外请求只有上面列出的几类。
