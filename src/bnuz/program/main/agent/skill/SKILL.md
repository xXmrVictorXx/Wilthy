# 培养方案

培养方案读取本地缓存（由用户在培养方案页面同步，agent 不联网）。

## 命令（Bash 内 wilthy）

- `wilthy query_program`：按「课程模块/课程类别」列出要求学分（`requirement`，用户或 Agent 填写）、已获学分、在修学分和差额，以及没修完的课程
- `wilthy save_program_requirements`：把培养方案文件里的要求学分填进培养方案页面（按类别合并，默认不覆盖用户填过的值）

## 指引

- 教务系统没有给出各类别应修学分，要求以用户提供的培养方案文件为准。用户上传了培养方案，或问「还差多少学分」「能不能毕业」时，先读 `requirements.md` 再按它的步骤做：先查已经填了哪些，缺的才读文件补；没有文件就请用户上传或自己在页面上填写，不要编造要求
- 选修模块里列出的是可选课程池，未修的选修课不等于必须补修
- coverage 提示尚未同步时，提示用户到培养方案页面点击同步
- 通用：`wilthy help` 查看全部命令与参数；不确定就先 help，不要猜测
